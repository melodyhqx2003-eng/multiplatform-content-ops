# 抖音平台规律库

状态：初始化。当前尚无账号自身验证数据；以下只定义研究与运营框架，不把未验证经验写成确定规律。

## 平台任务

抖音单独作为短视频内容平台管理，不直接复制小红书图文结构，也不套用闲鱼交易描述逻辑。

每次处理抖音内容时，优先判断：

- 内容目标：播放 / 完播 / 停留 / 点赞 / 评论 / 分享 / 关注 / 私信 / 咨询 / 成交
- 内容形式：口播 / 录屏教程 / 实操演示 / 案例拆解 / 问题解决 / 对比测试 / 图文视频 / 其他
- 目标用户
- 用户当前问题
- 视频核心承诺或价值
- 前几秒需要让用户立即理解什么
- 正文信息如何按视频节奏展开
- 行动引导放在哪里最自然

## 重点研究维度

### 1. 选题与用户场景

记录：
- 用户为什么会停下来观看
- 搜索型需求与推荐流需求的差异
- 哪些问题适合短视频解决
- 哪些内容适合系列化
- 哪些选题更容易带来咨询或成交

### 2. 视频开头 / 钩子

重点记录：
- 前几秒说了什么、展示了什么
- 是问题、结果、冲突、案例、演示还是直接结论
- 首屏字幕承担什么信息
- 是否快速让用户知道“看完能得到什么”
- 哪类开头带来更好的停留和完播

### 3. 正文结构与节奏

重点记录：
- 信息出现顺序
- 每个信息点时长
- 是否先给结果再解释
- 是否使用步骤、对比、错误示范、实际操作
- 画面变化、字幕、口播和录屏之间的配合
- 哪个位置出现明显流失或互动

### 4. 标题 / 文案 / 关键词

重点记录：
- 视频标题或发布文案的关键词
- 是否对应真实搜索需求
- 标题与视频首屏是否一致
- 关键词是否帮助用户迅速理解主题
- 是否存在夸张、承诺过度或降低信任的表达

### 5. 封面与首帧

重点记录：
- 封面是否清楚表达主题
- 首帧与封面是否一致
- 最大信息点是什么
- 是否存在过多文字或视觉噪音
- 封面对主页访问、搜索结果和点击的影响

### 6. 互动与转化

重点记录：
- 评论区最常出现的问题
- 哪类内容带来关注
- 哪类表达带来私信/咨询
- 服务或商品承接位置
- 从视频 → 主页 → 私信/咨询 → 成交的实际路径

### 7. 数据复盘

每条视频尽量记录：
- 发布时间
- 时长
- 播放量
- 平均播放时长（如可获得）
- 完播相关数据（如可获得）
- 点赞
- 评论
- 收藏
- 分享
- 新增关注
- 主页访问（如可获得）
- 私信/咨询
- 成交

没有某项数据时留空，不补造数据。

## 规则沉淀要求

### 已验证规律
只有在账号自身多条视频或高相关样本持续支持时，才可写入确定规律。

### 待验证假设
单条视频表现、外部经验、平台常见做法均先进入待验证状态，并明确测试变量。

## 与其他平台的边界

### 可跨平台参考
- 用户痛点
- 价值表达
- 信任感
- 真实案例
- 信息清晰度
- 服务承接逻辑

### 必须抖音单独验证
- 视频时长
- 前几秒钩子
- 剪辑节奏
- 口播结构
- 首帧/封面
- 字幕密度
- 视频标题与发布文案
- 完播、停留、互动之间的关系
- 视频内行动引导方式

禁止为了省事把小红书正文直接改成口播稿后发布；需要重新设计视频的观看路径和信息节奏。
