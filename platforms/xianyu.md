# 闲鱼平台规律库

状态：初始化，必须用闲鱼真实曝光、咨询与成交数据持续更新。

## 平台使用场景

闲鱼优先按交易场景理解，而不是把它当成小红书式内容平台。

重点研究：搜索商品/服务、比价、判断可信度、确认交付方式、发起咨询、议价、成交、售后。

## 内容目标

按商品/服务分别标注：曝光 / 点击 / 收藏 / 想要 / 咨询 / 有效咨询 / 成交 / 客单价 / 售后 / 复购。

## 重点变量

### 标题
- 核心搜索关键词
- 产品/服务名称
- 关键属性
- 用户最关心的结果或使用场景
- 是否存在堆砌关键词、过度营销或含糊表达

### 首图与图片
- 第一张是否快速说明卖什么
- 图片是否降低理解成本和信任成本
- 关键差异、交付内容、使用场景是否可视化
- 是否存在影响可信度的过度设计感或与实物/服务不符的展示

### 价格
- 标价是否与实际成交逻辑一致
- 是否产生“低价引流但实际完全不同”的信任损耗
- 套餐、范围、额外费用是否清楚

### 商品/服务描述
优先研究以下结构：
1. 是什么
2. 适合谁
3. 能解决什么问题
4. 具体包含什么
5. 交付/使用方式
6. 边界与注意事项
7. 咨询前需要知道什么

### 信任
重点观察：
- 描述是否具体
- 信息是否一致
- 是否明确边界
- 是否有可验证的经验/案例
- 回复速度和回复质量
- 售后说明

## 当前待验证假设

1. 闲鱼的高转化文案可能比小红书更依赖“搜索关键词 + 清晰交易信息 + 信任降低风险”，而不是长篇内容种草。
2. 标题、价格、首图与描述之间的一致性可能直接影响咨询质量和成交率。
3. 对服务类商品，明确交付范围和不包含内容，可能减少低质量咨询并提升成交效率。

以上均为待验证假设，不能直接写成已验证规则。

## 禁止直接套用的小红书逻辑

- 不默认使用小红书式情绪钩子
- 不默认使用同一套标签逻辑
- 不默认把收藏/点赞当核心成功指标
- 不默认把正文教程价值放在交易信息之前

## 复盘时重点记录

- 商品/服务类型
- 曝光
- 点击/浏览
- 收藏/想要
- 咨询数
- 有效咨询数
- 成交数
- 成交金额
- 退款/售后
- 标题版本
- 首图版本
- 标价与实际成交价
- 关键词
- 描述结构
- 常见咨询问题
- 未成交原因
